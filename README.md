# Country Explorer 🌍

Aplicación web desarrollada con Next.js que permite explorar países, 
banderas y datos en tiempo real mediante integración con REST Countries API.

## 🚀 Tecnologías
- Next.js
- Tailwind CSS
- Framer Motion
- REST Countries API

## 🔍 Funcionalidades
- Búsqueda de países
- Visualización de banderas
- Modal con detalles
- Normalización de texto (acentos)


## 📦 Instalación
npm install
npm run dev
